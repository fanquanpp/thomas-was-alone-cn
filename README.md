## 📖 简介

《Thomas Was Alone》是由 **Mike Bithell** 开发、2012 年发售的极简风格平台解谜游戏。几个不同形状的色块,在冷静幽默的英式旁白下,讲述了一个关于友情与自我的小故事。游戏虽好,但全程英文旁白与界面对不少玩家是道门槛。

本仓库提供该游戏 Steam PC 版的**完整中英双语汉化补丁**:

| 汉化范围 | 说明 |
| --- | --- |
| 旁白字幕 | 全部关卡的旁白字幕,中文 + 英文原文对照显示 |
| 章节引言 | 每章开头的引言文本,双语对照 |
| 界面菜单 | 主菜单、选关、设置、暂停菜单等全部界面文本 |
| 制作人员名单 | 职务名称翻译,人名保留英文原文 |
| 硬编码文本 | 修复 10 处程序内写死的英文(跳过提示、`--LOCKED--`、窗口/全屏选项等) |
| 中文字体 | 补丁已**内嵌中文字体**,无需系统安装任何字体 |

**汉化规模**:共 317 条文本全部翻译,其中 231 条经人工精修(精简句式、中文标点、保留原文冷幽默风格)。

## ✨ 特点

- **中英对照**:字幕与引言同时显示中文译文和英文原文,方便对照品味原文
- **一键安装**:安装脚本自动定位 Steam 游戏目录,无需手动寻找路径
- **自动备份**:首次安装自动备份所有被替换的原版文件,随时可还原
- **无痕卸载**:一键还原英文原版,不留任何残留
- **安全无副作用**:只替换文本与字体资源文件,不修改游戏程序逻辑,不影响存档、成就与 Steam 云存档

## 🎮 安装教程

### 环境要求

- Windows 7 SP1 及以上系统(安装脚本使用系统自带的 PowerShell)
- **Steam 版**《Thomas Was Alone》(其他渠道版本未测试)
- 无需任何前置补丁或运行库

### 方式一:一键脚本安装(推荐)

1. **下载补丁**:打开本仓库右侧的 [**Releases**](../../releases) 页面,下载最新版的 `ThomasWasAlone-CN-Patch-vX.X.X.zip`;
2. **解压**:将压缩包解压到任意位置;
3. **运行**:双击 `安装汉化补丁.bat`;
4. **确认目录**:脚本会自动检测 Steam 游戏目录并显示路径,直接**回车**确认即可;若未检测到,按提示输入游戏根目录(或把文件夹直接拖进窗口后回车);
5. **完成**:看到 `汉化安装完成!` 字样即成功,**启动游戏**享受中文!

> 💡 首次安装时,脚本会在 `ThomasWasAlone_Data\_原版备份` 中自动备份全部被替换的原版文件,这是之后卸载还原的依据,请勿手动删除。

### 方式二:手动替换安装

1. 下载并解压补丁(同上);
2. 打开 Steam 客户端 → 库中右键《Thomas Was Alone》→ **管理** → **浏览本地文件**,打开游戏根目录;
3. 把补丁内的 `ThomasWasAlone_Data` 整个文件夹**复制**到游戏根目录;
4. 系统提示"目标中已包含同名文件夹"时,选择 **"替换目标中的文件"**(只会覆盖 129 个文本/字体资源文件,不会删除其他任何文件);
5. 启动游戏即可。

> 💡 手动方式安装前,建议先把游戏目录中的 `ThomasWasAlone_Data` 文件夹复制一份到别处留作备份。

## 🔧 卸载教程

任选其一:

- **脚本还原**:双击补丁目录中的 `卸载汉化补丁.bat`,脚本会把 `_原版备份` 中的原版文件全部还原;
- **Steam 校验**:Steam 库中右键游戏 → 属性 → 已安装文件 → **验证游戏文件的完整性**,Steam 会自动将所有被修改的文件还原为官方原版。

## ❓ 常见问题(FAQ)

<details>
<summary><b>安装后游戏还是英文?</b></summary>

- 确认 `ThomasWasAlone_Data` 文件夹复制到了**游戏根目录**(与 `ThomasWasAlone.exe` 同一级目录);
- 手动安装时确认替换提示中选择的是"替换目标中的文件";
- 确认游戏没有被 Steam 设置为只读或其他版本(本补丁仅适配 Steam 版)。
</details>

<details>
<summary><b>字幕出现方块/缺字?</b></summary>

本补丁已内嵌完整中文字体,正常情况不会缺字。若出现,请确认下载的是完整的 Release 压缩包(不要单独下载仓库中的部分文件),问题依旧请到 [Issues](../../issues) 反馈。
</details>

<details>
<summary><b>影响存档和成就吗?</b></summary>

不影响。补丁只替换文本与字体资源文件,不改动任何游戏逻辑、存档数据与成就系统。
</details>

<details>
<summary><b>支持 GOG / Epic 或其他渠道版本吗?</b></summary>

本补丁针对 **Steam 版**制作并测试,其他渠道版本未经测试。若资源结构一致原则上可用,但请自行备份后尝试,不做保证。
</details>

<details>
<summary><b>游戏启动后是全屏,想改成窗口模式?</b></summary>

游戏主菜单选择 OPTIONS → WINDOW MODE 即可切换窗口/全屏(该选项已被汉化)。
</details>

<details>
<summary><b>游戏更新后补丁会失效吗?</b></summary>

《Thomas Was Alone》自 2012 年发售后官方已长期未更新,本补丁基于当前 Steam 最新版本制作,理论上长期有效。若未来官方更新导致不兼容,欢迎提 Issue,我会尽快适配。
</details>

## 📝 汉化说明

- **翻译格式**:关卡字幕与章节引言采用"中文译文 ↵ 英文原文"双语对照;菜单与界面文本采用"中文 + 空格 + 英文";职员表职务翻译、人名保留英文;
- **翻译风格**:原作旁白以冷静克制的英式冷幽默写成,译文在忠实原意的基础上进行了本土化润色,保留了大量的原文韵味;
- **字体方案**:游戏原生字体不含汉字,补丁将界面字体重定向至内嵌的**微软等线(DengXian)字体子集**,并打包进补丁文件中,离线可用。
